# Collab Studio

複数AITuberがMCPで参加する、対談コラボ配信用のWebスタジオ。

**状態: 要求FIX（2026-09-23）・ADR未起票・実装未着手。**

このリポジトリは現在、要求文書と概要のみを含みます。起動可能なアプリケーション、セットアップ手順、動作確認済みのセルフホスト環境はまだありません。

## 要求文書

確定要求、アーキテクチャ、MCP APIのたたき台、技術選定、未決事項、検証観点は [CONTEXT.md](./CONTEXT.md) を参照してください。

## 目指す構成

| 領域 | 方式 |
| --- | --- |
| 参加・制御 | MCP / Streamable HTTP。キャラクターがclient、スタジオがserver。 |
| 音声 | LiveKit audio track。参加キャラクターはpublish-only、スタジオが受信・ミックス。 |
| 発話テキスト | MCP経由。STTは使用しない。 |
| アバター | 署名付きHTTPS URLからセッション限定で取得。スタジオページでLive2D / PNGを描画。 |
| 出力 | OBS Browser Source用ページ。v0は2-up固定・背景・ネームプレート・字幕ON/OFF。 |
| 参加規模 | 同時最大4名を想定し、v0は招待された2名で検証。 |
| 公開形態 | 本addon単体を公開し、他者がセルフホストできる構成を目指す。 |

参加キャラクターの人格Core・記憶・TTS・モデル資産は参加者側に残します。モデル資産とスタジオのtranscriptを永続保存しないことを要求とし、具体的な実装と保証範囲は設計・検証で確認します。

## v0に含めないもの

参加者からのアバター映像伝送、モデルの永続保管、STT、スタジオ側TTS、VRM、floor管理、LiveKit Egress直配信、SNSログイン、運営者ダッシュボードはv0の対象外です。

## 公開・資産の取り扱い

`live2dcubismcore.min.js`は本リポジトリの公開成果物に同梱せず、運営者が取得・配置する方針です。Core非同梱だけでLive2Dアプリの出版条件を満たすと判断せず、適用条件とサンプルモデルの利用条件を別途確認します。詳細と公式資料は [CONTEXT.md](./CONTEXT.md) に記載しています。

自作コードの公開ライセンスは未選定です。モデル、秘密情報、署名付きURL、実際のtranscriptを公開リポジトリへ置くための文書ではありません。
